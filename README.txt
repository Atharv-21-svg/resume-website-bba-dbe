ATHARV RAUT - RESUME WEBSITE
============================

FILES
-----
index.html   - The content and structure of the website.
style.css    - All colours, fonts, layout, spacing and responsive styling.

HOW TO RUN THE WEBSITE
----------------------
1. Download and unzip the project folder.
2. Keep index.html and style.css in the same folder.
3. Double-click index.html. It should open in your browser.
4. To edit the website, open the files in Notepad, VS Code or another text editor.

IMPORTANT EDIT BEFORE PUBLISHING
--------------------------------
Open index.html and find:
  YOUR_EMAIL@example.com
Replace both occurrences with your real email address. Also update the mailto: value
in the same link. Do not leave the sample address in the submitted website.

The project links currently point to the UnderRadar and StealthComps prototypes:
  https://underradar.lovable.app
  https://stealthcomps.lovable.app
Check that you still want these links shown before submitting.

HOW TO HOST ON GITHUB PAGES
---------------------------
1. Sign in to GitHub in a computer browser.
2. Open the repository you used for the earlier HTML assignment, if you have one.
   The assignment asks you to use the same repository. If you genuinely do not have
   an earlier repository, create a new public repository for this website.
3. Upload index.html and style.css to the top/root level of that repository.
   Keep both files together in the same folder. README.txt is optional for the site,
   but useful to keep in the repository.
4. Commit the uploaded files.
5. In the repository settings, open the Pages section and enable deployment from
   the main branch and the root folder (/(root)). Save the setting.
6. GitHub Pages will publish the website at the URL shown in the Pages section.
   Open that URL in a private/incognito window to check that it works.
7. Copy both the live website URL and the repository URL for the assignment PDF.

WHAT TO CHECK BEFORE SUBMISSION
-------------------------------
[ ] The website opens and all sections are visible.
[ ] The navigation links jump to the right sections.
[ ] The email address is your real email address.
[ ] Project links open the intended projects.
[ ] The live website link works when you are signed out of GitHub.
[ ] The repository link opens correctly.
[ ] Your PDF contains both links and your design explanation.

TECHNOLOGY
----------
This project uses HTML and CSS only. It does not require JavaScript, an API, a
framework, a build step or an external font download.
